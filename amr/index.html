Calculation Formulas & Standard References (Level 2 S2 Slab Rev.02)
1. Load Accumulation, UDL & 3-Point Rocking EN 1991-1-1 §6.3 · EN 1991-3 · TR34 / ASTM E1155

Gravity loads accumulate top-down. Preset A (2-Skate) uses 60/40 CG split × 0.35 rocking × Φ1.20 (19.63 kN/wh). Preset B (6-Skate) uses 60/40 side split × 1/3 heavy-side share = 20% bias × 0.35 × 1.20 (6.85 kN powered/fork; 3.42 kN SRS-6 roller), with 25%/30% bias sensitivity.

Mgross = mpay + mbase + 2mpow + Nfol(mfol + madd) (1.1)
UDL = Mgross · g / 1000Lbase · Wbase ≤ 7.50 kN/m² (1.2)
Fskate,peak = Wgross · max(1N, Bias) · Φ1.20 (1.3)
Fwheel,peak = 0.35 · Fskate,peakwfork (wfork=1 TS-10T, 2 coax SRS-6) (1.4)
2. Mode 1 — Surface Bearing (Gent + Hertz) Gent (1958) / ASTM D2240 · BS 8110-1 Cl. 5.2.3.4

Each wheel type is evaluated with its own tread width (Lw = 85 mm TS-10T, 30 mm SRS-6). At 95 Shore A, E = 43.83 MPa and E* = E/(1−ν2) = 58.44 MPa (ν=0.50) or 57.68 MPa (ν=0.49), compared against fb = 0.4fcu = 12.0 MPa.

EPU = 0.0981 (56 + 7.62336 S)0.137505 (254 − 2.54 S) [MPa],   E* = Ew1 − ν2 (2.1)
b = √4 F Rπ Lw E*,   AHertz = 2b Lw (2.2)
Pmean = FAHertz ≤ fb = 0.4fcu = 12.0 MPa (2.3)
3. Mode 2 — Point Load (Qk) & Coaxial Fork Check EN 1991-1-1 / BS 6399 · BS 8110-1 Cl. 3.7.7 · EC2 Cl. 6.4

Elevated Level 2 slabs designed for 7.5 kN/m² carry allowable concentrated point load Qk = 4.5 kN (Static) / 7.0 kN (Peak). Dual coaxial rollers on SRS-6 share a single shear cone, so both individual rollers and the dual-wheel fork cluster are checked alongside slab punching shear vEd.

Qk,static ≤ 4.5 kN,   Qk,peak ≤ 7.0 kN (individual wheel & coax fork) (3.1)
BS 8110 (1.5d): VEd = 1.60 Ffork,   u1 = u0 + 12d,   vEd,1 = VEdu1 d (3.2)
4. Mode 3 — Strip Width be & Multi-Point Beam Solver BS 5400 / EC2 45° Dispersion · BS 8110-1 Cl. 3.5.2.2

Default 45° thickness dispersion spreads TS-10T (b=0.60 m) across be = b + 2h = 0.90 m on h=0.15 m (outer SRS-6 uses 1.00 m strip). Multi-point SFD/BMD outputs per-meter Vmax and Mmax against S2 benchmarks (L=2.80 m: Mref=7.35 kNm/m, Vref=10.50 kN/m).

Mref = w L28,   Vref = w L2 (w = 7.5 kN/m strip) (4.1)
be,45° = bskate + 2h  |  be,8110 = bskate + 2.4x(1 − xL),   Peff = Pbe (4.2)
